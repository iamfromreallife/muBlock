# MV3uBlockOrigin — uBlock Origin Lite with classic-style UI

This is a **work-in-progress community fork** of [uBlock Origin Lite](https://github.com/uBlockOrigin/uBOL-home), intended to present its existing Manifest V3 popup and dashboard in a classic [uBlock Origin](https://github.com/gorhill/uBlock) style. It is **not an official uBlock Origin release**, and does not add Manifest V2 filtering capabilities.

## Install

Once the `Build Chrome extension` GitHub Actions workflow has successfully finished and committed the generated distribution:

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Choose the `dist/chrome-unpacked` folder containing `manifest.json`.

The unpacked build is generated by copying the official upstream uBlock Origin Lite Chromium distribution, then applying the two UI-only entrypoint overlays in `overlay/`. It is also uploaded as a ZIP artifact by the build workflow.

## Development and provenance

- **Functional upstream:** https://github.com/uBlockOrigin/uBOL-home (the checked-out commit is written to `dist/UPSTREAM_COMMIT.txt` at build time).
- **Classic UI reference:** https://github.com/gorhill/uBlock.
- **UI overlay:** `overlay/js` and `overlay/css`.
- **Build injection:** `scripts/apply_overlay.py`.
- **Integrity tests:** `tests/test_package.py`.

The build must preserve the original `manifest.json`, filter lists, service worker, picker, zapper, unpicker, and other Lite runtime files. Only `popup.html` and `dashboard.html` are edited to reference new UI assets; the original Lite JavaScript and CSS remain intact.

### Custom filters

Lite supports both sandbox filters (with its CodeMirror-based editor) and per-site cosmetic filters generated by the element picker. The UI foregrounds the former in a classic-style **My filters** pane, while leaving the original per-site filter manager available below it. These distinct stores are not merged.

### Current limitations

The classic styling is an adaptation, not a full transplant of uBlock Origin's MV2 UI. Features not provided by uBlock Origin Lite, such as MV2-only dynamic filtering controls or uBO network statistics, are intentionally not displayed or simulated. Browser-level tests must be performed in a real Chrome extension environment; the workflow's included tests verify distribution integrity and static integration.
